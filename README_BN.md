# প্রজ্ঞা AI — প্রাথমিক ওয়েবসাইট

## কী আছে
- বাংলা ওয়েব ইন্টারফেস
- মোবাইল-উপযোগী চ্যাট ডিজাইন
- `/api/chat` নামে সার্ভার endpoint
- API key HTML/ব্রাউজারে রাখা হয়নি

## অবস্থা
এটি প্রাথমিক starter project। AI provider এখনো যুক্ত করা হয়নি। তাই চ্যাটে এখনো প্রকৃত AI উত্তর আসবে না।

## চালাতে
Node.js ইনস্টল থাকা কম্পিউটার/হোস্টিংয়ে:
1. টার্মিনালে এই ফোল্ডারে যাও
2. `npm install`
3. `npm start`
4. ব্রাউজারে `http://localhost:3000` খোলো

## পরের ধাপ
অভিভাবক/যোগ্য প্রাপ্তবয়স্কের সহায়তায় উপযুক্ত AI provider-এর শর্ত ও বিনামূল্যের ব্যবহারসীমা যাচাই করে সার্ভারের `server.js`-এ সংযোগ যোগ করতে হবে। API key কখনো `public/index.html`-এ বা প্রকাশ্য GitHub repository-তে দেবে না।
